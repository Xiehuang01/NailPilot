# NailPilot Frontend

Vue 3 frontend for the NailPilot Meituan Hackathon demo.

## Stack

- Vue 3
- Vite
- TypeScript
- Tailwind CSS v4
- Pinia
- Element Plus
- lucide-vue-next
- GSAP

## Quick Start

1. Install dependencies:
   `pnpm install`
2. Copy environment variables:
   `cp .env.example .env`
3. Start the dev server:
   `pnpm dev`

Default URL:

- `http://localhost:3000`

## Scripts

- `pnpm dev`: start Vite on port `3000`
- `pnpm lint`: run Vue/TypeScript checks
- `pnpm build`: build production assets into `dist/`
- `pnpm preview`: preview the production build
